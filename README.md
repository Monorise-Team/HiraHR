# HiraHR

Kadry Monorise w przeglądarce: kartoteka pracowników, umowy i stanowiska, urlopy i nieobecności oraz akta osobowe. Zakresem funkcji wzorujemy się na Personio dopasowanym do polskiego prawa pracy ([ADR-0104](https://github.com/Monorise-Team/MonoriseDocumentation/blob/main/adr/ADR-0104-hirahr-personio-polish-labour-law.md)).

Repozytorium powstało 27.11.2026. Kod pojawi się w kolejnych etapach.
